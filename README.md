# Shubhi & Raghav — Wedding Celebrations

Royal Wedding Invitation web application for Shubhi & Raghav at Ananta Spa & Resort, Jaipur, Rajasthan (3–5 December 2026).

Built with React, Vite, TanStack Router, TailwindCSS, and Framer Motion for [InviteStory](https://invitestory.in).

## Development

```bash
bun install
bun run dev
```

## Production Build

```bash
bun run build
bun run preview
```
